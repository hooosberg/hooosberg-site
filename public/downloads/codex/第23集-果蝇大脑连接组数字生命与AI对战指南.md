# 第23集｜我和13.9万个果蝇神经元玩了一下午游戏：数字生命与AI对战实录

> 本指南配合视频评测使用：解析 Princeton FlyWire 计划数字化的 13.9 万个真实果蝇大脑神经元与 5000 万个突触连接组，以及在电脑中驱动实时游戏对抗的机制。

---

## 核心概念：大模型 vs 神经连接组

| 对比维度 | 现代大语言模型（如 ChatGPT / Claude） | 果蝇生物神经连接组（Connectome） |
| :--- | :--- | :--- |
| **底层机理** | 统计概率与 Transformer 注意力机制 | 真实生物突触与神经元动作电位模拟 |
| **知识来源** | 互联网人类文本的大规模预训练 | 演化赋予的生物反射与本能回路 |
| **行为模式** | “假装”成为某种角色或输出答案 | 受到外界刺激（光、触碰）后产生生物本能反应 |
| **算力开销** | 云端集群超大显存推理 | 本地多线程物理/生物仿真模拟 |

## 实验环境搭建与接入

1. **开源连接组项目**：基于 Princeton 与 Janelia 联合发布的 FlyWire 完整果蝇全脑数据集；
2. **感知输入与运动映射**：
   - 输入：游戏环境中的障碍物距离与敌对目标坐标，映射为果蝇复眼感受野电位刺激；
   - 输出：果蝇翅膀震颤频率与肢体转角输出，映射为游戏角色的上下左右移动向量。
3. **观察结果**：
   - 展现出高度拟真的躲避本能、环形盘旋与应激反应；
   - 证明了具身智能（Embodied AI）不仅依赖海量参数，微小生物的精密连接结构同样蕴藏极高智力密度。
