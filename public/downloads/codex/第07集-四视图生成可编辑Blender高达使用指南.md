# 第07集｜最新GPT-6 Astra 实测：一张四视图生成可编辑 Blender 高达使用指南

> 本指南配合视频实测使用：通过 AI 生成的一张高达正/侧/背/透视四视图，驱动 GPT-6 Astra 完成 439 个独立网格部件与 18 根骨骼的参数化 3D 建模。

---

## 模型结构与集合规划

- **工程环境**：Blender 4.5.1 LTS（向下兼容 Blender 3.6+）
- **部件统计**：439 个独立网格部件（Mesh），均已将几何中心整理到自身原点（Origin to Geometry）
- **骨架绑定**：18 根基础 FK 骨骼（包含躯干、颈部、肩关节、上臂、前臂、手腕、腰部、大腿、小腿与脚掌）
- **图层集合（Collections）**：
  - `01_HEAD_头部组件`：眉檐、折面前凸面罩、内收下颌、向后掠天线
  - `02_CHEST_胸腹装甲`：斜面凸起胸甲、进气道格栅、收窄腹腔
  - `03_WAIST_腰部裙甲`：前裙甲、侧裙甲（带微外翻角度）、后裙甲
  - `04_LIMBS_四肢与装甲`：肩甲凹腔结构、肘部关节轴承、膝部双联液压杆与脚掌
  - `05_BACKPACK_推进背包`：主推喷口、姿态控制微喷口
  - `06_WEAPON_武器配件`：光束步枪（Rifle.R）与折叠盾牌（Shield.L）
  - `09_RIG_摆姿骨架`：控制全身姿态的 FK 骨骼系统
  - `10_REFERENCE_原始四视图`：内嵌正交参考视图（默认隐藏）
  - `11_STUDIO_摄影棚`：预设 5 个机位正交与透视相机及三点布光系统

---

## 核心操作与快捷键指引

1. **编辑几何形状**：
   - 鼠标左键选中目标网格部件，按 `Tab` 键进入 Edit Mode；
   - 所有倒角均保留在修改器中（`Editable edge bevel`），可在修改器面板中无损调节倒角段数与权重。
2. **更换涂装与材质**：
   - 选中部件进入材质面板，已预设标准着色器：经典纯白高光、联邦蓝、明亮红、警示黄与深灰金属机械关节材质。
3. **调整动作与姿势（Pose Mode）**：
   - 在大纲视图展开 `09_RIG_摆姿骨架` 集合，取消骨架的隐藏眼睛图标；
   - 选中骨架，按 `Ctrl + Tab`（或左上角下拉菜单）进入 **Pose Mode**；
   - 选中任意一根骨骼，按 `R` 旋转手臂或转头，按 `G` 移动；
   - **姿态重置**：按 `A` 全选所有骨骼，按快捷键 `Alt + R`（清空旋转）、`Alt + G`（清空位移）、`Alt + S`（清空缩放）即可瞬间恢复默认站姿。
4. **渲染出图**：
   - 按小键盘 `0` 切换到活动摄像机（默认已定位至最佳 3/4 英雄视角）；
   - 按 `F12` 即可渲染出图。

## 自动化重构脚本说明

本工程附带 `重建脚本.py`。若需要根据新的四视图重新生成模型，可在 Blender 的 Scripting 窗口加载并执行脚本，脚本将自动根据正交图素重新生成顶点坐标并组装集合。
