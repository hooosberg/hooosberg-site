# 第07集｜不用折腾环境！三合一高价值工作流指南

> 本指南配合视频使用：在一个统一的工作流中串联 AI 生图、股票量化分析与自动化编程，开箱即用体验海外顶尖大模型。

---

## 三合一工作流架构

1. **AI 视觉工作流**：内置生图与海报处理引擎，直接对接 ChatGPT 与 Stable Diffusion 接口；
2. **量化金融分析工作流**：集成 Claude Code 运行环境，支持抓取实时财经数据并自动回测指标；
3. **自动化编程工作流**：本地文件读写权限、实时终端交互与语法错误自愈。

---

## 典型使用链路

```bash
# 启动本地一体化环境
npm run start --workspace ~/ai-projects

# 唤起 Claude Code 进行量化分析
claude-code "分析指定科技股过去 30 天均线走势，输出 Markdown 图表报告"
```
