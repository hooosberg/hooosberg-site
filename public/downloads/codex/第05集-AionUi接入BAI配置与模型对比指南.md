## ⚙️ 二、AionUi 表单配置对照表

在 AionUi 中点击 **设置 (Settings)** → **模型设置 (Models)** → **添加模型**，按下方表格对应填写：

| 配置项 | 填写内容 / 设置值 | 详细说明 |
| :--- | :--- | :--- |
| **模型平台** | **自定义** | 保持默认的「自定义」即可 |
| **API 请求地址** | `https://api.b.ai/v1` | B.AI 标准 API 基础端点 |
| **完整 URL 开关** | **关闭（默认）** | 保持灰色关闭状态，客户端会自动拼接请求路径 |
| **API Key** | `sk-...` | 粘贴在 [chat.b.ai/key](https://chat.b.ai/key) 生成的密钥 |
| **模型名称** | *填入具体模型 ID* | 填写想使用的模型 ID（详见下方免费与常用清单） |
| **视觉输入** | **自动识别** | 保持默认即可，模型支持看图时会自动启用 |
| **OpenAI 请求接口** | **自动识别（推荐）** | 保持默认即可，系统会自动走兼容接口协议 |

## 📝 六、极速上手操作三步走

1. **第一步：获取 Key**
   - 访问 [B.AI 注册页面](https://chat.b.ai/chat?invite_code=UCPRMG) 注册并登录。
   - 前往 [API Key 页面](https://chat.b.ai/key) 点击 **Create API Key**，复制生成的 `sk-...` 密钥。
2. **第二步：配置 AionUi**
   - 打开 AionUi 客户端，进入 **设置** → **模型设置** → **添加模型**。
   - 请求地址填入 `https://api.b.ai/v1`，粘贴您的 API Key，模型名称填入 `deepseek-v4-flash` 或 `glm-5.3-flash`。
   - 点击 **确定** 保存。
3. **第三步：开始对话**
   - 在对话窗口顶部切换为你刚添加的模型，发送一条消息即可开启免费、高速的 AI 对话与编码体验！
