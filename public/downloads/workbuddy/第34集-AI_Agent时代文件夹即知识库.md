# 第34集｜别再学 Obsidian 了！AI Agent 时代，知识库就是一个文件夹

> AI Agent 时代，我们还有必要花大量时间学习和维护复杂的“第二大脑”吗？核心思考与极简实践指南。

---

## 核心观点

**知识库本来没有那么复杂。你的 Markdown、PDF、图片、Word 和各种资料文件，本身就是知识库。**

过去我们需要：
- 自己整理文件层级；
- 手动打各种标签；
- 做双向链接与反向链接；
- 维护复杂的知识图谱。

但现在 **Codex、WorkBuddy、Claude Code** 这类 AI Agent 已经可以直接读取、搜索、整理和修改本地文件。

---

## 未来知识库的三层架构

```text
┌───────────────────────────────────────────────┐
│     表现层 (Obsidian / WitNote / 编辑器)       │
├───────────────────────────────────────────────┤
│     智能层 (AI Agent / 本地检索 / 跨文件推理)  │
├───────────────────────────────────────────────┤
│     数据层 (本地文件夹 / Markdown / Office)   │
└───────────────────────────────────────────────┘
```

**底层是文件 → 中间是 AI Agent → 最上面才是 Obsidian、WitNote 这样的表现层。**

不要为了管理知识，最后变成了管理“知识管理软件”。

---

## 落地实践建议

1. **保持纯文本与通用格式**：以 Markdown、TXT、CSV、PDF 为主，任何 AI 工具都能随时切入读取。
2. **少做仪式感分类，多建任务工作区**：按项目或任务建立独立文件夹，任务结束后归档。
3. **把索引与搜索交给 Agent**：直接用自然语言向智能体下达指令，让 Agent 在整个文件夹中定位事实并产出交付物。
