# 第33集｜豆包办公＋公文 Skill：开源公文 Skill 规范公文生成指南

> 本集演示如何把 GitHub 开源公文 Skill 装进 AI（豆包办公 / WorkBuddy），现场让 AI 按党政公文规范生成通知并导出标准 Word 文件，以及如何结合历史公文写作习惯持续优化。

---

## 核心流程

1. **获取与导入开源公文 Skill**：
   - 使用开源公文知识库 `lieflat-gongwen`（包含文章结构模板、写作视角与认知框架、不同文种示例）。
   - 将 Skill 提示词或规则配置导入豆包办公或 WorkBuddy 的专属 Skill / 智能体空间。
2. **规范公文生成**：
   - 输入发文目的、受文单位、主要事项与政策依据。
   - AI 严格按照国家公文格式（标题、主送单位、正文三段式、生效日期、落款）生成规范公文。
3. **导出标准格式 Word**：
   - 保证公文红头、发文字号、字号行距、附件说明等格式规范保真。
4. **个性化微调与习惯沉淀**：
   - 喂入单位历史公文范例，让 AI 学习本单位特定的语言习惯和固定口径。

---

## 典型提示词

### 提示词｜按公文 Skill 规范起草专项通知

```text
基于已挂载的公文 Skill 规范，以“临河县五行矿业”名义起草一份《关于开展安全生产检查的通知》：
要求：
1. 主送单位为各矿区车间、各职能部门；
2. 内容包括检查范围（井下作业区、通风机房、尾矿库）、重点排查隐患、整改责任人与整改时限；
3. 符合国家标准公文格式与语言风格，严谨得体；
4. 输出可直接转换为规范 Word 排版的内容。
```

- [ ] 文种选择正确（通知 / 请示 / 报告 / 函）。

- [ ] 导出的 Word 符合红头公文排版基本规范。
