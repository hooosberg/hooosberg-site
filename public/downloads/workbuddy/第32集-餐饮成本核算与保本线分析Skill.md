# 第32集｜WorkBuddy＋Excel：餐饮成本核算与保本线分析Skill

> 案例背景：看完勇哥的餐饮账，用 WorkBuddy 做出一个可以改数字、能跟着重新计算的 Excel 工作簿，并沉淀为可复用 Skill 与餐饮成本专家。

---

## 本期核心目标

1. 把经营信息整理成「开店成本核算」和「保本线分析」两张表。
2. 让输入项、公式项和结果项分开，改一个数字就能看到结果变化。
3. 把确认的核算方法整理成 Markdown Skill，再做成可复用的专家。

---

## 核心知识点

- **一个工作簿，两张表**：开店成本核算看前期投入，保本线分析看日常经营。
- **表格必须区分输入、公式和结果**：结果单元格必须由公式计算，不能直接填死。
- **验证公式最简单的方法**：每次只改一个输入项，看相关结果会不会跟着变化。
- **通用性**：餐饮只是案例，零售、服务业和项目制业务也能用同样的成本核算思路。

---

## 可复用提示词

### 提示词 1｜生成两张 Excel 表

> **思路**：先上传图片，再发送提示词。要求输入区、公式区和结果区分离，全靠公式驱动计算。

```text
我已经上传两张餐饮经营截图。请根据图片内容，在一个 Excel 工作簿中生成两张带公式的表。

第一张表叫开店成本核算，包含面积、房租、付款方式、押金、宣传、设备等输入项，自动计算建店成本和固定成本；如果数据和单位完整，再计算每日盈亏平衡点。

第二张表叫保本线分析，包含营业额、毛利率、房租、人工、水电等输入项，展示现状、调整后和差异。

要求：
1. 两张表放在同一个工作簿中。
2. 明确标出哪些单元格可以输入，哪些单元格是公式结果。
3. 所有结果使用 Excel 公式计算，不要直接填写最终数字。
4. 截图中看不清的字段、金额或单位请标为待确认，不要猜。
5. 完成后告诉我每张表应该修改哪些输入项，以及修改后重点看哪些结果。
```

---

### 提示词 2｜把核算方法整理成 Skill

> **思路**：将成功经验规则化，沉淀为标准 Skill，便于后续同类业务直接套用。

```text
请根据本次两张 Excel 表已经确认的字段和计算逻辑，整理一个餐饮成本核算 Skill，并保存为 Markdown 文件。

Skill 需要包含：适用场景、输入字段和单位、两张表各自的计算逻辑、操作步骤、常见错误和验收方法。

字段或规则不完整时，请列出待确认项，不要补造内容。
```

---

### 提示词 3｜把 Skill 做成专家

> **思路**：将 Skill 挂载为智能体专家，实现交互式引导与咨询。

```text
请使用这些餐饮成本核算 Skills 创建一个餐饮成本核算专家。

专家接到任务后，先确认用户提供的金额单位、时间周期和关键输入；再指导用户生成或检查开店成本核算和保本线分析两张 Excel 表；最后说明需要修改哪些输入项、哪些结果会受到影响，以及还有哪些内容待确认。
```

---

## 最终检查清单

- [ ] 工作簿里有「开店成本核算」和「保本线分析」两张表。
- [ ] 修改一个输入项后，相关结果会自动重新计算。
- [ ] 表格里没有任何 `#REF!`、`#VALUE!` 或 `#DIV/0!` 等计算错误。
- [ ] 绿色/公式区域受保护，实际经营数据由使用者人工复核。
