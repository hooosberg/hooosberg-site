# 第12集｜我们一直误解了自动化办公？从Excel到AI智能体的范式换代

> 本指南配合视频科普使用：梳理人类办公从竹简账簿到 Office，再到自主 AI Agent 的四次工业级跃迁。

---

## 办公演进的四个时代

1. **第一代：竹简与纸质流水线**（从记录事实到手工分发流转）；
2. **第二代：Office / Excel 程序化时代**（把纸搬进电脑，由人写好函数公式）；
3. **第三代：RPA 流程自动化机器人**（按固定规则录屏与模拟点击）；
4. **第四代：LLM 原生自主 Agent**（由目标驱动，AI 自主感知、拆解、编写代码并交付成果）。

---

## 职场人工作思维的换代法则

1. **从“操作手”变成“任务负责人”**：不再纠结 VLOOKUP 怎么写，而是思考业务口径是否合理；
2. **永远保留原始事实，把草稿交给 Agent**：输入资料不破坏、清洗结果另存、过程留下可核对审计日志；
3. **把重复经验沉淀为可复用 Skill**：将一次成功的 Prompt 封装成规范工作区，实现一劳永逸。
